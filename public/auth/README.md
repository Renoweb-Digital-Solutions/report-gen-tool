# Authentication brand assets

`google-g.png` is Google's official icon, downloaded from:
https://developers.google.com/static/identity/images/g-logo.png

Used by `app/features/auth/components/GoogleAuthButton.js`. Keep its colors and
aspect ratio unchanged. The surrounding motion is implemented separately in
`app/features/auth/google.module.css`; Google Sans Medium is self-hosted through
the existing Next.js font pipeline.

Brand reference: https://developers.google.com/identity/branding-guidelines
